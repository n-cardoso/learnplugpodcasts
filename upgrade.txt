LearnPlug Podcasts upgrade notes
===============================

1.0 (2026050401)
----------------
- Privacy API coverage extended to include `learnplugpodcasts.owneruserid` metadata.
- Added owner-context discovery and export for privacy requests.
- Added owner anonymisation in user/context data deletion routines.

1.0 (2026050236)
----------------
- Fixed remaining duplicated caption language labels by stripping hidden Unicode direction markers from language names.
- Applied this normalization in both server-side caption label generation and client-side caption selector rendering.

1.0 (2026050235)
----------------
- Fixed caption selector label duplication in learner player (example: `English (en) (EN)` now shown once as `English (EN)`).
- Applied the same normalization logic to runtime caption selector rebuilding in AMD player code.

1.0 (2026050234)
----------------
- Added recommended channel completion model in activity settings:
  - listen to at least N episodes
  - each counted episode must reach at least X% listened
- Set channel completion as the default mode for new activities.
- Updated completion labels/help text to guide teachers toward reliable podcast completion criteria.

1.0 (2026050233)
----------------
- Fixed Moodle-native grading integration in activity settings.
- Added persisted `grade` field for instances and migration from legacy `gradeenabled`.
- Fixed completion "Receive a grade / Passing grade" compatibility by exposing standard grading controls.
- Updated gradebook item setup to use configured grade maximum instead of a hardcoded value.

1.0 (2026050232)
----------------
- Fixed episode sorting by using numeric publish timestamps in list ordering.
- Added teacher episode filters for status, transcript availability, media source, and season.
- Added additional sort modes (title A-Z/Z-A, duration longest/shortest) for faster teacher navigation.

1.0 (2026050231)
----------------
- Deployment release baseline set to `1.0` (stable).

1.0.49 (2026050230)
-------------------
- Updated plugin activity icon to the new purple podcast identity mark.

1.0.48 (2026050229)
-------------------
- Hardened caption selector label normalization to prevent duplicated language-code suffixes (server and client side).

1.0.47 (2026050228)
-------------------
- Fixed Moodle App "Download all episodes" payload to include audio files only.
- Prevents podcast cover/episode images from appearing as items in the bulk download list.

1.0.46 (2026050227)
-------------------
- Fixed caption selector label duplication for locales like English/Portuguese where Moodle translation names
  include trailing language codes.

1.0.45 (2026050226)
-------------------
- Redesigned Moodle App episode list to expandable/tappable episode rows.
- Episode image and full audio player are now shown inside the expanded episode panel.
- Improved mobile playback visibility to avoid collapsed "play-icon only" behavior.

1.0.44 (2026050225)
-------------------
- Learner channel player controls updated to a cleaner iOS-like style with higher button visibility.
- Removed outlined container line around the learner player control row.
- Compacted teacher/admin episode cards to reduce whitespace and improve episode list density.

1.0.43 (2026050224)
-------------------
- Fixed caption language label duplication in learner selector (for example `Português - Portugal (pt) (PT)`).
- Labels now render cleanly as `Language name (CODE)`.

1.0.42 (2026050223)
-------------------
- Fixed Moodle App template parsing error caused by invalid Angular binding quoting in offline download payloads.

1.0.41 (2026050222)
-------------------
- Increased per-episode caption upload capacity to support many language `.vtt` files.
- Improved caption language detection from filenames (supports patterns like `captions.pt.vtt`,
  `captions-pt.vtt`, and `captions_pt-br.vtt`).
- Improved fallback labels for unknown caption language tags by showing the uploaded filename.
- Hardened caption validation so one invalid file no longer clears all existing caption tracks.

1.0.40 (2026050221)
-------------------
- Improved Moodle App playback and offline behavior for episode audio.
- Mobile audio player now uses `core-external-content` so downloaded files are reused offline.
- Mobile download buttons now pass explicit JSON payloads for per-episode and bulk downloads.

1.0.39 (2026050220)
-------------------
- Completed removal of legacy automation remnants from documentation and language packs.
- Added an extra upgrade cleanup pass for legacy background jobs/config to cover previously updated sites.

1.0.19 (2026050107)
-------------------
- Added teacher analytics dashboard inside activity view (capability `mod/learnplugpodcasts:viewreports`).
- Added overall metrics cards (enrolment, engagement, average listened, completion, total listening time, published coverage).
- Added per-episode analytics table (listeners, engagement, completion rate, listened time, duration, last activity).
- Added new analytics aggregation service `\mod_learnplugpodcasts\local\service\analytics_service`.

1.0.18 (2026050106)
-------------------
- Added native Moodle App support via `db/mobile.php` and `\mod_learnplugpodcasts\output\mobile`.
- Added mobile activity page template (`templates/mobileapp/mobile_view_page.mustache`) for episode playback.
- Added offline download actions in the Moodle App (per-episode and batch episode download).
- Added mobile prefetch file metadata so downloaded episodes remain available offline.

1.0.17 (2026050105)
-------------------
- Added new-episode learner notifications via Moodle messaging provider (`mod_learnplugpodcasts:newepisode`).
- Added site-level controls to enable/disable notifications and default activity behavior.
- Added teacher activity-level toggle to activate/deactivate notifications per podcast series.
- Notifications are sent when an episode transitions to published state, with duplicate-send protection.

1.0.16 (2026050104)
-------------------
- Transcript and caption automation tasks moved to Moodle background (adhoc) tasks.
- Added per-episode background status tracking (queued/running/completed/failed) for teachers.
- Added AJAX polling in episode management view to update progress automatically.

1.0.15 (2026050103)
-------------------
- Improved resilience on shared hosting during subtitle/transcript generation.
- After long remote HTTP calls, the plugin now resets the Moodle DB connection before
  file and record writes, preventing "MySQL server has gone away" errors.

1.0.14 (2026050102)
-------------------
- Restored transcript download availability after automated transcription.
- Automated transcription now creates a fresh downloadable `.txt` transcript file in
  `episodetranscript` after replacing stale files.

1.0.13 (2026050101)
-------------------
- Fixed transcript download behavior for public/learner views:
  - `.vtt` files are no longer used as transcript download links from `episodetranscript`.
  - Transcript, caption, and attachment file areas now force browser download.
- Automated transcript generation now clears stale uploaded transcript files in `episodetranscript`
  so the displayed transcript is not linked to unrelated legacy files.

1.0.12 (2026043007)
-------------------
- Normalized Moodle boilerplate spacing across PHP files for plugin checker compliance.
- Fixed `episode_form` global-state sniff by adding `MOODLE_INTERNAL` check and removed useless validation override.
- Reworked caption fence cleanup logic to avoid forbidden backtick literal usage.
- Reordered language strings and wrapped long settings lines to satisfy coding style checks.

1.0.11 (2026043006)
-------------------
- Fixed public landing and public episode navigation initialization in Boost-based themes.
- Public pages now bind `$PAGE` to the correct course + cm pair via `set_course()` and `set_cm()`.
- Resolves coding error: "The course you passed to \$PAGE->set_cm does not correspond to the \$cm."

1.0.10 (2026043005)
-------------------
- Added pre-flight audio size checks for transcription and timed caption generation.
- Added explicit user-friendly error for oversized audio uploads (before and on HTTP 413 responses).
- This avoids raw API failure text and clarifies the actionable size limit path.

1.0.38 (2026050219)
-------------------
- Privacy API compliance pass:
  - Added missing `timecreated` metadata declaration for learner progress records.
  - Removed non-user automation log table metadata declaration from privacy provider.
  - Added Moodle messaging subsystem disclosure for episode notifications.
  - Improved context discovery query with `DISTINCT` to avoid duplicate contexts.

1.0.37 (2026050218)
-------------------
- Removed automation features (transcription, caption generation, and caption translation) from settings and teacher UI.
- Removed automation diagnostics panel/actions from activity view.
- Stopped scheduling fallback queue processing in `db/tasks.php`.
- Added upgrade cleanup to cancel queued/running legacy jobs, remove related ad-hoc rows, and clear legacy plugin config values.

1.0.9 (2026043004)

- Added automatic caption generation + translation admin settings and teacher episode actions.
